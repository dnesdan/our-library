# OUR LIBRARY — Agent Notes

This repository is the interactive prototype for Dan and Lucia's shared digital ebook library. It is an application, not a marketing site. Preserve the feeling of a warm, personal home library in every change.

## Non-negotiables

- The catalog and 3D room represent the same collection.
- Keep the 3D room, moving ladder, fireplace, reading lamp, book retrieval, and reader functional.
- Keep interactions touch-friendly and honor reduced-motion preferences.
- Prefer cover color, warm wood, paper, charcoal, and restrained motion over dashboard styling.
- Demo reading state may persist in `localStorage`; no backend is required.

## Development

- `npm run dev` starts the local preview.
- `npm run build` must pass before deployment.
- Keep the Cloudflare-compatible vinext structure and `.openai/hosting.json` intact.
